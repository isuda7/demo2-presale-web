# 미확인 · 확정 필요 항목

## A. 확정이 필요한 문구(임의로 정하지 않음)

| 항목 | 위치 | 현재 값 |
|---|---|---|
| 개인정보 수집·이용 목적 | `shared/config/base.ts` → `privacy.purpose` | `[미확정]` |
| 개인정보 보유·이용 기간 | `privacy.retention` | `[미확정]` |
| 동의 거부 권리·불이익 | `privacy.refusal` | `[미확정]` |
| 동의 체크 문구 | `shared/form.ts` → `consentField.label` | 초안 "개인정보 수집·이용에 동의합니다." |
| 동의문 버전 | `privacy.version` | `draft-0` — 확정 시 올릴 것 |

현장별 문구는 `shared/site.ts` 의 `overrides.privacy` 에 넣는다. `npm run check` 가 `[미확정]` 이 남아 있으면 경고한다.

## B. 자료에서 확인되지 않거나 판단이 필요한 것

1. **분양인지 임대인지** — PDF 는 "임대 문의", "100% 임대방식으로 직영운영"으로 표기되어 있다. 본문은 카탈로그 그대로 "임대"로 두었고, 메뉴명은 중립적인 "관심고객 등록". 사이트 성격(분양/임대) 확정 필요.
2. **대표번호** — PDF 표지 그대로 "임대문의 3274-3709"를 표시. 지역번호가 없어 **전화 걸기 링크는 만들지 않았다**. 지역번호·현재 유효 여부 미확인.
3. **자료 시점(2016-01-19)** — 아래 내용은 카탈로그 시점 기준이며 현재와 다를 수 있다. 화면에는 카탈로그 문구 그대로 실었다.
   - 건설기간 "2014년 8월 ~ 2016년 12월 (28개월 예정)"
   - 신안산선 "(예정)", 입지 지도의 "2023년 개통예정"
   - 호텔 '글래드 마포' 입점, 층별 MD(입점 업종) 계획
4. **카탈로그 안의 서로 다른 숫자**(어느 쪽이 맞는지 미확인, 각 쪽 표기 그대로 둠)
   - 호텔 객실: 2쪽 "379 객실" / 5쪽 "378실"
   - A블럭 층수: 2쪽 "지상24층" / 11쪽 단면도 "8F-23F 호텔"
5. **수정한 오탈자** — 9쪽 "지원지설" → "지원시설", 2쪽 "컨벤션센터는 물론." → "물론,". 그 밖의 표기(캐쥬얼/캐주얼, 휴계공간 등)는 원문 유지.
6. **싣지 않은 내용** — 14쪽 "재계순위 25위", "신용등급 AAA", 효성그룹 사업부문(PU) 목록: 2016년 기준의 회사 평가·조직 정보라 현재 사실과 다를 가능성이 커서 제외. 필요하면 최신 자료로 확인 후 추가.
7. **8F~23F(호텔) 평면** — 카탈로그에 없음.
8. **이미지 사용권** — 사진 대부분은 카탈로그의 "이미지컷"(참고 이미지)이다. 웹 게시 사용권(스톡 사진 라이선스 범위 포함) 확인 필요. 화면에는 사진마다 "이미지컷" 표기와 고지문을 달았다.
9. **글꼴** — 카탈로그 글꼴(YD 윤고딕, DIN, Myriad, Trajan)은 웹 라이선스가 확인되지 않아 Google Fonts(Noto Sans KR, Barlow, Cinzel)로 대체. Google Fonts 는 외부 서버에서 불러온다.
10. **로고** — 표지 엠블럼을 이미지로 잘라 사용(보라 배경 포함). 원본(벡터) 로고 파일 확인 필요.
11. **문의사항 필수 여부** — 초안은 선택 입력.
12. **연락처 형식** — 초안은 0으로 시작하는 9~11자리(휴대전화·지역번호) 허용.
13. **신청 상태값** — 초안 `신규 / 연락완료 / 보류` (`apply.statuses`).
14. **보유기간 경과 자동 삭제** — 보유기간이 정해지지 않아 구현하지 않음.

## C. 구현하지 않았거나 검증하지 못한 것

- Vercel·Turso 실제 배포(로컬만 확인) — `doc/배포.md` 의 "배포 시 확인할 점"
- 로그인 시도 횟수 제한·신청 도배 제한(서버리스 환경에서는 외부 저장소가 필요) — 신청은 숨김 칸(honeypot)만 적용
- 관리자 계정은 비밀번호 1개(다중 계정·접속 기록 없음)
- 유형(템플릿) — 적용하지 않음(현장 설정에 직접 적용)
