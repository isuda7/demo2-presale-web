# 개발 환경

## 폴더

| 폴더 | 내용 |
|---|---|
| `api/` | Vercel 진입점(`api/index.ts`) — `backend/app.ts` 를 그대로 연결 |
| `backend/` | Hono API(`app.ts`, `routes/`), DB(`db.ts`, `repo.ts`), 인증(`auth.ts`), CSV, 로컬 서버(`dev.ts`) |
| `frontend/` | 페이지 HTML, `src/`(화면 스크립트·스타일), `build/layout.ts`(빌드 시 레이아웃 주입), `vite.config.ts` |
| `shared/` | 설정(`config/`, `site.ts`), 신청 폼 정의·검증(`form.ts`) — 화면과 서버가 같이 쓴다 |
| `doc/` | 설계 문서 |
| `scripts/` | 점검(`check.ts`), DB 준비(`db-init.ts`), 페이지 골격 생성(`new-page.ts`) |

## 규칙

- **상대 import 에는 `.js` 확장자**를 붙인다(파일은 `.ts` 여도). Vercel 서버리스에서 확장자 없는 ESM import 는 실행 시 크래시가 난다. `tsconfig`(NodeNext)와 `npm run check` 가 함께 잡아낸다.
- 비밀값은 **환경변수로만** 다룬다. 코드·문서·커밋에 값을 적지 않는다. 로컬은 `.env.local`(저장소 제외).

## 환경변수

| 이름 | 용도 | 로컬 | 배포 |
|---|---|---|---|
| `ADMIN_PASSWORD` | 관리자 로그인 비밀번호 | 필수(없으면 로그인 비활성) | 필수 |
| `TOKEN_SECRET` | 관리자 토큰 서명(32자 이상 무작위) | 필수 | 필수 |
| `TURSO_DATABASE_URL` | Turso DB 주소 | 비우면 `./local.db` | 필수(없으면 API 오류) |
| `TURSO_AUTH_TOKEN` | Turso 접근 토큰 | 비움 | 필수 |
| `API_PORT`, `WEB_PORT` | 로컬 포트(기본 8797, 5190) | 선택 | — |

## API

모든 응답 `Cache-Control: no-store`. 오류는 `{ "error": "메시지" }`.

| 메서드 · 경로 | 인증 | 설명 |
|---|---|---|
| `GET /api/health` | — | `{ ok, db: "local" \| "turso" }` |
| `GET /api/apply/status` | — | `{ closed, message }` — 화면은 이 값으로 폼/마감 안내를 정한다 |
| `POST /api/apply` | — | 신청 저장. 201 성공 · 422 검증 실패(`fields`) · 403 마감 |
| `POST /api/admin/login` | — | `{ password }` → HttpOnly 쿠키 발급. 503 = 환경변수 미설정 |
| `POST /api/admin/logout` | — | 쿠키 삭제 |
| `GET /api/admin/me` | — | `{ authed, configured }` |
| `GET /api/admin/applications` | 필요 | `?q=&status=&from=YYYY-MM-DD&to=YYYY-MM-DD&page=` (기간은 한국시간 기준) |
| `PATCH /api/admin/applications/:id` | 필요 | `{ status }` — 설정의 `apply.statuses` 값만 허용 |
| `DELETE /api/admin/applications/:id` | 필요 | 영구 삭제 |
| `GET /api/admin/export.csv` | 필요 | 목록과 같은 조건. UTF-8 BOM(엑셀 한글), 수식 주입 방지 처리 |
| `GET /api/content?page=<key>` | — | 화면 편집 수정본 `{ overrides: { "<페이지>.<구획>": html } }`. 브라우저는 매번 확인, Vercel CDN 30초 캐시 |
| `GET /api/assets/:id` | — | 화면 편집에서 올린 이미지(1년 캐시) |
| `PUT /api/admin/content/:slot` | 필요 | `{ html }` 구획 수정본 저장(허용 태그만 남김, 200KB 이하) |
| `DELETE /api/admin/content/:slot` | 필요 | 수정본 삭제 → 원래 내용 |
| `POST /api/admin/assets` | 필요 | multipart `file` — JPG·PNG·WEBP, 3MB 이하 |

## 화면 편집(관리자)

관리자로 로그인한 상태에서 사이트 화면을 열면 아래쪽에 **편집 바**가 생긴다. "이 화면 편집"을 누르면:

| 대상 | 방법 |
|---|---|
| 제목·문장·목록·표·버튼 글자 | 눌러서 그 자리에서 고침(붙여넣기는 글자만, Enter 는 줄바꿈) |
| 사진 | 마우스를 올리면 나오는 "이미지 교체" / "설명"(대체 텍스트) — 큰 사진은 브라우저에서 긴 변 2000px 로 줄여 올림 |
| 링크·버튼 주소 | "링크 주소" |
| 배경 이미지(메인·랜드마크) | "배경 이미지 교체" |
| 구획 되돌리기 | 구획 왼쪽 위 표시의 "원래대로" |

- **저장 단위는 구획**(`<페이지>.<구획>`). 고친 구획은 주황 테두리, 저장하면 DB(`content_overrides`)에 들어가고 방문자 화면에 반영된다(Vercel CDN 캐시로 최대 30초 지연).
- **방문자에게는 편집 코드가 가지 않는다.** 방문자 화면의 스크립트(`content-loader`)는 수정본을 바꿔 끼우는 일만 하고, 편집기(`src/editor/`)는 관리자 힌트 쿠키(`admin_ui`)가 있을 때만 별도 파일로 불러온다. 편집기는 다시 `/api/admin/me` 로 실제 로그인을 확인하고, 저장 API 는 HttpOnly 토큰으로만 허용된다. `npm run check` 가 빌드 HTML 에 편집기가 직접 들어가지 않았는지 검사한다.
- **로그아웃**(편집 바 또는 관리자 페이지)하면 두 쿠키가 지워지고 화면을 다시 불러와 편집 바가 사라진다.
- 저장 HTML 은 서버에서 정리한다: 스크립트·이벤트 속성·외부 이미지·`javascript:` 링크 제거, 배경은 사이트 안 이미지 경로만 허용.
- 편집할 수 없는 곳: 머리말·메뉴·꼬리말(설정값 `shared/site.ts`), 신청 폼 자체(`shared/form.ts`).

### 수정본을 소스로 굳히기

방문자 화면은 빌드된 원본을 먼저 그린 뒤 수정본으로 바꿔 끼우므로, 수정된 구획은 잠깐 원본이 보였다가 바뀔 수 있고 검색엔진은 원본을 읽는다. 수정이 안정되면 굳힌다:

```bash
npm run content:pull -- --clear
```

수정본을 `frontend/content/…html` 로, 올린 이미지를 `frontend/public/images/uploads/` 로 옮기고 DB 수정본을 지운다 → 커밋·배포. (`.env.local` 에 Turso 값이 있으면 운영 DB 를 읽는다.)

## 신청 마감 스위치

`shared/site.ts` 에서 `overrides.apply.closed = true` → 배포. 화면은 폼 대신 `closedMessage` 만 보이고, 서버는 `POST /api/apply` 를 403 으로 거부한다(둘 다 같은 설정값을 읽음).

## DB

- 테이블 `content_overrides`(화면 편집 수정본), `assets`(올린 이미지, BLOB)
- 테이블 `applications`: `id, name, phone, message, privacy_agreed, privacy_version, status, created_at(UTC ISO), updated_at`
- API 첫 요청 때 테이블을 자동 생성한다(`CREATE TABLE IF NOT EXISTS`). `npm run db:init` 으로 미리 만들 수도 있다.
- `privacy_version` 에는 신청 당시의 동의문 버전(`config.privacy.version`)이 남는다. 동의문을 확정·변경할 때 버전을 올린다.
- IP·브라우저 정보 등은 **수집하지 않는다**(동의문에 없는 항목이므로).

## 인증

- 비밀번호는 `ADMIN_PASSWORD` 와 시간차 공격에 안전한 방식으로 비교.
- 로그인 성공 시 `TOKEN_SECRET` 으로 서명한 JWT(HS256, 유효시간 `admin.sessionHours`)를 `HttpOnly; SameSite=Strict; Path=/api/admin` 쿠키로 발급(배포 환경은 `Secure` 추가). 화면 스크립트는 토큰에 접근하지 않는다.
