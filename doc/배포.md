# 배포 (GitHub → Vercel, Turso)

> 아래 절차는 **아직 실제로 수행·검증하지 않았다**. 로컬 실행·빌드만 확인했다.

## 1. Turso

1. Turso 에서 DB 생성 → DB URL(`libsql://…`)과 인증 토큰 발급
2. 테이블은 API 첫 요청 때 자동 생성된다. 미리 만들려면 `.env.local` 에 Turso 값을 넣고 `npm run db:init` (끝나면 로컬용으로 다시 비운다)

## 2. GitHub

저장소를 만들고 푸시. `.env.local`, `local.db` 는 `.gitignore` 로 제외되어 있다 — 푸시 전 `npm run check` 로 확인.

## 3. Vercel

1. Vercel 에서 GitHub 저장소 가져오기(Import)
2. 빌드 설정은 `vercel.json` 에 있다: 빌드 `npm run build`, 출력 `frontend/dist`, `/api/*` → `api/index.ts`
3. Settings → Environment Variables 에 `ADMIN_PASSWORD`, `TOKEN_SECRET`, `TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN` 등록(Production·Preview 각각)
4. 배포 후 확인
   - `/api/health` → `{"ok":true,"db":"turso"}`
   - `/apply/` 신청 → `/admin/` 로그인 → 목록·CSV

## 배포 시 확인할 점(미검증)

- Vercel 이 `api/index.ts` 의 메서드별 export(`GET/POST/PATCH/DELETE`)를 Node.js 런타임으로 실행하는지
- rewrite 후 Hono 가 받는 요청 경로가 원래 경로(`/api/...`)로 유지되는지 — 404 가 나면 이 부분을 먼저 본다
- Preview 배포에도 Turso 환경변수를 넣을지(넣지 않으면 Preview 의 API 는 오류)
